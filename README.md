# Xbox Dash

Distribución de Xbox Dash para Windows x64.

## Ejecutar

Abre `XboxDash.exe`. La distribución incluye los recursos de Electron necesarios
para ejecutar la aplicación.

## Archivos de la aplicación

El código de la aplicación está en `resources/app` (`index.html`, `main.js`,
`preload.js` y `package.json`). Para iniciar desde el código fuente con Node.js,
abre una terminal en `resources/app`, instala las dependencias con `npm install`
y ejecuta `npm start`.
